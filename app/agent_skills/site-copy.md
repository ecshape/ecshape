# Website copy (conversion copywriter)

- Hero: who it is for + the result + time frame + proof ("ליווי אונליין לגברים עסוקים — לרדת 6–10 ק"ג ב־12 שבועות, עם תוכנית שמתאימה ללו"ז שלך"). One primary CTA.
- Every section answers one objection: "will it fit me?", "is it worth it?", "who is the coach?", "what happens after I sign up?".
- Benefits over features; numbers and real results; testimonials with name + result + time.
- FAQ: price range, time per week, home vs gym, food restrictions, what if I miss, how fast results.
- Keep the same meaning in he / en / fr; adapt idioms instead of translating word by word.
- Apply with `set_site_text` (path + language), one change per call — the trainer confirms. Read current texts with `get_site_content` first.
