# QA tickets

- Title: what is wrong + where ("Chat: bottom bar hidden on phones").
- Body: steps to reproduce, expected vs actual, device/language, screenshot reference.
- Priority: high = blocks clients or payments; normal = visible problem with a workaround; low = polish.
- One problem per ticket. Use `create_qa_ticket` / `update_qa_ticket` — the trainer confirms.
